# Умный кредитный кабинет предпринимателя — Frontend

Клиентский веб-кабинет и автоматизированное рабочее место (АРМ) андеррайтера для цифрового кредитного конвейера малого и микробизнеса (Альфа-Банк).

---

## 🚀 Быстрый запуск

### 1. Локально для разработки
```bash
cd frontend
npm install
npm run dev
```
Интерфейс откроется по адресу: `http://localhost:5173`.

### 2. Запуск в Docker
Фронтенд автоматически упакован в Multi-stage Dockerfile с Nginx:
```bash
docker build -t alfa-credit-frontend .
docker run -p 80:80 alfa-credit-frontend
```

---

## 🎯 Архитектура и стек технологий

* **Фреймворк:** React 19 + TypeScript (строгий режим `strict: true`, `verbatimModuleSyntax`).
* **Сборка:** Vite 8.
* **Стилизация и дизайн:** `@alfalab/core-components` (дизайн-система Альфа-Банка) + `@tailwindcss/vite` v4.
* **Сетевой слой:** Axios + перехватчики авторизации Bearer JWT + Polling статусов каждые 1.5 сек.
* **Типизация контрактов:** 100% автогенерация из `docs/openapi.yaml` через `openapi-typescript` (`npm run codegen`).
* **Иконки:** `@alfalab/icons-glyph` и `lucide-react`.

## 👑 Демо-панель (DemoBar) и 5 сквозных сценариев

В самом верху интерфейса закреплена панель быстрого тестирования для жюри, позволяющая в 1 клик переключаться между эталонными профилями:

1. 🟢 **«Идеальный клиент» (ООО «Альфа Логистика», ИНН 7701000001):**
   * Зрелый бизнес (4 года), выручка 50 млн ₽.
   * **Результат:** Моментальный переход `SUBMITTED` ➔ `ENRICHMENT` ➔ `SCORING` ➔ `AUTO_APPROVED` ➔ График платежей ➔ Подписание простой ЭП ➔ Зачисление средств (`DISBURSED`).
2. 🟡 **«ИП Смирнов» (ИНН 7701000002):**
   * Запрос 5 млн при обороте 8 млн ₽ (высокая долговая нагрузка PTI > 35%).
   * **Результат:** `COUNTER_OFFERED` — наглядное сравнение запрошенных и встречных условий (3.25 млн ₽) с объяснением комфортного платежа.
3. ⚪ **«ТехноСтарт» (ИНН 7701000003):**
   * Молодой IT-бизнес (8 месяцев), серая зона скоринга (`GREY`).
   * **Результат:** `MANUAL_REVIEW` ➔ Переход в АРМ Андеррайтера ➔ Запрос баланса (`WAITING_DOCUMENTS`) ➔ Загрузка файла клиентом ➔ Одобрение андеррайтером.
4. 🔴 **«Негатив Трейд» (ИНН 7701000004):**
   * Просрочка 115 дней в БКИ.
   * **Результат:** Срабатывает стоп-фактор `bki_overdue_90` ➔ `REJECTED` с понятным объяснением и рекомендациями.
5. 🔵 **«ООО Мегастрой» (ИНН 7701000005):**
   * Запрос 15 млн при лимите продукта 10 млн ₽.
   * **Результат:** Встречное предложение на предельный лимит продукта.
6. 💼 **«АРМ Андеррайтера»:**
   * Рабочее место риск-офицера банка с фильтрами по статусам и зонам риска, анализом PD (вероятности дефолта) и кнопками принятия решений.
